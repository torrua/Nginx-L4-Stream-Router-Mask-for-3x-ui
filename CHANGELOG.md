## [9.4.0] - 2026-10-22

### Добавлено
- **Пул SNI и нативная авторотация для VLESS Classic REALITY (`CLASSIC_SNI`):**
  - Поддержка задания нескольких доменов через пробел или запятую (например, поддоменов Microsoft или Google).
  - Сквозная нормализация, валидация и дедупликация доменов в Bash (`env.sh`, `wizard.sh`) и Python (`reconcile.py`).
  - Генерация маршрутов Nginx Stream L4 для всех доменов пула на порт `46443`.
  - Заполнение `realitySettings.serverNames` и генерация индивидуальных узлов `externalProxy` для каждого SNI.
  - Синхронизация записей таблицы `hosts` в SQLite БД 3X-UI с флагом `shuffle_host = 1` для рандомизации и клиентской балансировки через подписку (поддержка схем `snake_case` и `camelCase`).
- **Настраиваемый профиль uTLS Fingerprint (`REALITY_FINGERPRINT`):**
  - Возможность выбора профиля маскировки TLS (`chrome`, `firefox`, `safari`, `ios`, `android`, `edge`, `360`, `qq`, `random`, `randomized`; по умолчанию `firefox`).
  - Интерактивный TUI-выбор в визарде (`wizard.sh`) через новый универсальный компонент `prompt_select` (стрелки `↑`/`↓`, `Enter`, цифры `1`..`N` и автоматический фоллбек).
  - Подстановка в `realitySettings.settings.fingerprint`, `externalProxy` и колонку `fingerprint` таблицы `hosts`.
- **Автоматическая реконсиляция пула и fingerprint (`src/xray/inbounds.py`):**
  - `smart_reconcile_inbound` обнаруживает изменения пула доменов и fingerprint, автоматически обновляя конфигурацию Xray и узлы `externalProxy` в базе данных.
- **Модульные и интеграционные тесты:**
  - Тесты парсинга пула в Bash, синхронизации таблицы `hosts` с флагом `shuffle_host` и реконсиляции fingerprint в `tests/test_audit_regressions.py`.

## [9.3.0] - 2026-10-22

### Добавлено
- **Единый криптографический модуль Python (`src/common/crypto_engine.py`):**
  - Централизованная чистая реализация Curve25519 / RFC 7748 X25519 без сторонних бинарных зависимостей.
  - Единая генерация и валидация ключевых пар для WireGuard / AmneziaWG (base64 standard), Xray Reality (base64url unpadded) и DNSTT (64-символьный hex).
  - Строгая валидация длины ключей (ровно 32 байта) и отсечение некорректных форматов.
- **Единый движок резервного копирования Python (`src/common/backup_engine.py`):**
  - Централизованное создание манифеста резервной копии v2.0 с контрольными суммами SHA-256.
  - Потоковая верификация целостности архива и защита от Path Traversal при распаковке (`tarfile.data_filter` в Python 3.12+ со строгим fallback-фильтром на более ранних версиях).
  - Безопасное атомарное извлечение и сухой аудит архивов (`--dry-run restore`).
- **Комплексные модульные тесты новых движков (`tests/test_python_engines.py`):**
  - 17 тестов, покрывающих эталонные векторы RFC 7748, битовые операции clamp, генерацию ключей, валидацию SQLite БД, создание и аудит манифестов, а также проверку изоляции импортов и автономного развертывания контроллера.

### Изменено
- **Устранение дублирования кода согласования панели (`maintain.main.sh` и `panel/reconcile.py`):**
  - Вся логика синхронизации инбаундов и настроек панели в `maintain.main.sh` теперь переиспользует единый модуль `src/panel/reconcile.py` через директиву сбощика `# @include`.
  - Устранено дублирование свыше 1000 строк вложенного Python-кода.
  - Сохранение пользовательских названий (remarks) инбаундов в базе SQLite при повторном согласовании вместо перезаписи значениями по умолчанию.
  - Автоматическое обнаружение активных сервисов по наличию конфигураций и служб systemd (Mieru, MASQUE, ShadowTLS, Wstunnel, Zapret, NaïveProxy, DNSTT), даже при запуске без предварительно переданных переменных окружения.
- **Ужесточение безопасности загрузчика конфигурации (`src/common/config.sh`):**
  - `load_config_data_safe` теперь запрещает перезапись критических системных переменных окружения (`PATH`, `LD_PRELOAD`, `LD_LIBRARY_PATH`, `LD_AUDIT`, `IFS`, `SHELL`, `EUID`, `UID`, `PPID`, `BASH_ENV`, `ENV`, `CDPATH`, `PYTHONPATH`, `PYTHONHOME`, `PROMPT_COMMAND`, `GLOBIGNORE` и др.).
  - Безопасная загрузка конфигураций в `manage-services.main.sh` переведена с `source` на `load_config_data_safe`.
- **Автономное развертывание AmneziaWG контроллера (`src/awg/setup.sh`):**
  - При установке контроллера в `/root/awg` модуль `crypto_engine.py` теперь автоматически копируется и встраивается рядом с `manage_clients.py` для надёжной работы `awg-cli` без внешних зависимостей.

### Исправлено
- **Тихий сбой интеграции AdGuard Home в 3X-UI (`src/adguard/setup.sh`):**
  - Добавлен недостающий импорт `os` (`import sqlite3, json, os`) во встроенном Python-обработчике интеграции AdGuard Home с SQLite-базой 3X-UI. Ранее обращение к `os.environ` вызывало `NameError: name 'os' is not defined` и приводило к тихому сбою настройки DNS-маршрутизации.
- **Скрытый сбой генерации ключей DNSTT при согласовании панели (`src/panel/reconcile.py`):**
  - Добавлен надежный импорт `generate_dnstt_keypair` с многоуровневым поиском пути. Ранее вызов `generate_dnstt_keypair()` в `reconcile.py` приводил к `NameError`, тихо маскируемому блоком `except Exception: pass`, блокируя первичную генерацию ключей DNSTT.
- **Отказоустойчивость изолированного импорта криптоядра:**
  - `src/awg/manage_clients.py` и `src/xray/keys.py` оснащены многоуровневым fallback-импортом `crypto_engine` (пакетный импорт, локальный каталог `/root/awg`, относительный `Path(__file__)`), исключая `AttributeError` при вызове скриптов вне корня репозитория.
- **Устранение избыточных копий X25519:**
  - `src/awg/manage_clients.py`, `src/awg/setup.sh`, `src/xray/keys.py`, `src/installer/steps.sh` и `src/panel/reconcile.py` переведены на использование единого `crypto_engine`.

## [9.2.0] - 2026-10-22

### Добавлено
- Встроенный веб-портал диагностики (LibreSpeed + MTR) с единой авторизацией по персональному токену (SSO) и изоляцией под пользователем `www-data`.
- Резервное копирование базы данных 3X-UI «на лету» через горячий SQLite API без разрыва сессий клиентов.
- Режим предварительного аудита восстановления (`maintain.sh --dry-run restore`) с проверкой SHA-256 хэшей и `PRAGMA integrity_check`.
- Изоляция порта AdGuard Home (`10053`) для устранения конфликтов со стандартным портом 53 `systemd-resolved`.
- Криптографический аудит загрузок: проверка всех внешних бинарных компонентов по манифесту хэшей SHA-256 (`components-manifest.json`).

### Изменено
- Безопасный загрузчик `.env` без `eval` (`load_config_data_safe`).
- Поддержка аргументов командной строки при запуске однострочников через `curl | bash -s -- --check`.
- Раздельные правила маршрутизации для российских доменов и IP-подсетей.
