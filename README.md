## 📌 Почему этот VPN не блокируют

Обычные протоколы (WireGuard, OpenVPN) легко вычисляются и блокируются провайдерами по характерным признакам трафика.

В этом проекте защита устроена иначе:

1. **Сервер выглядит как обычный сайт.** Снаружи это сайт компании с настоящим SSL-сертификатом.
2. **Один порт 443 для всего.** И сайт, и VPN работают на стандартном HTTPS-порту `443`. Провайдер видит только обычные зашифрованные веб-сессии.
3. **Nginx распределяет запросы:**
   * Открыли сайт в браузере или пришёл бот-сканер → Nginx показывает веб-сайт.
   * Подключилось приложение с вашим VPN-ключом → Nginx сразу передаёт трафик ядру Xray, и у вас работает интернет.
   * Открыли секретный адрес панели управления → загружается веб-интерфейс 3X-UI.
4. **Защита для мобильных сетей (AmneziaWG):**
   * В пакеты добавляется случайный шум (Junk), поэтому системы ТСПУ сотовых операторов (МТС, Билайн, Мегафон, Т2) не могут распознать протокол WireGuard.

## ⚡ Быстрый запуск за 3 шага

### 1. Подготовьте VPS и домен
* Арендуйте виртуальный сервер (VPS) с **Ubuntu 22.04 / 24.04** или **Debian 11 / 12**.
* Купите любой домен и направьте его на IP сервера (A-запись в DNS).  
  *Если используете Cloudflare: обязательно включите режим **DNS Only (Серое облако)**.*

### 2. Запустите установку
Подключитесь к серверу по SSH под пользователем `root` и выполните:

```bash
curl -sSL https://raw.githubusercontent.com/torrua/Nginx-L4-Stream-Router-Mask-for-3x-ui/main/setup_mask.sh | sudo bash
```
Скрипт спросит домен, email для сертификата и секретный адрес панели, после чего сам всё установит и настроит.

### 3. Создайте готовые подключения
Запустите скрипт автонастройки панели 3X-UI:
```bash
curl -sSL https://raw.githubusercontent.com/torrua/Nginx-L4-Stream-Router-Mask-for-3x-ui/main/configure_3xui.sh | sudo bash
```
Готово. Откройте панель в браузере (`https://ваш-домен/секретный_путь/`), добавьте пользователя и отсканируйте QR-код в приложении на телефоне.

## 💡 Какой протокол когда использовать

| Протокол | Для чего подходит | Как работает |
| :--- | :--- | :--- |
| **AmneziaWG (v3.1 / v2.0)** | Смартфоны на мобильном интернете (4G/5G) и роутеры Keenetic/OpenWrt | Маскирует заголовки случайными данными (Junk), фиксирует MTU 1280 (без зависаний пакетов), использует подсеть `/22` (до 1022 клиентов) и быстрый DNS от Control D. |
| **VLESS Reality** | Домашний Wi-Fi, компьютеры и ноутбуки | Скорость до 1 Гбит/с, минимальная нагрузка на процессор и аккумулятор устройства, маскировка под TLS 1.3. |
| **VLESS xHTTP** | Сети с жёсткой фильтрацией (офисы, публичный Wi-Fi) | Работает поверх чистого HTTP/2 (H2C) и шифруется `vlessenc`. Трафик неотличим от обычной загрузки сайтов. |
| **Hysteria 2** | Нестабильные линии с потерями пакетов | Работает по UDP (QUIC/HTTP/3) с протоколом BBR для разгона скорости. |

## 🎛️ Автоматическая настройка 3X-UI

Скрипт **`configure_3xui.sh`** настраивает базу данных панели 3X-UI без ручного ввода:
* **Сохраняет существующих пользователей:** обновляет системные параметры портов и протоколов, не затрагивая выданные ключи клиентов.
* **Выставляет правильные параметры:** отключает несовместимые опции (например, Vision на xHTTP), задаёт DNS от Control D (`76.76.2.0, 76.76.10.0`) и активирует параметры AmneziaWG для сотовых сетей.

Команда запуска:
```bash
curl -sSL https://raw.githubusercontent.com/torrua/Nginx-L4-Stream-Router-Mask-for-3x-ui/main/configure_3xui.sh | sudo bash
```

## 🛠️ Автоматический запуск для сисадминов (CLI)

Скрипт `setup_mask.sh` поддерживает ключи командной строки и файл конфигурации для запуска в скриптах и Ansible:

```bash
# Запуск с параметрами
sudo ./setup_mask.sh -y -d mydomain.online -m admin@mydomain.online -p /my-panel/ -s /my-sub/ -f 1

# Запуск через файл .env
cp setup_mask.env.example setup_mask.env
nano setup_mask.env
sudo ./setup_mask.sh -c setup_mask.env -y
```
