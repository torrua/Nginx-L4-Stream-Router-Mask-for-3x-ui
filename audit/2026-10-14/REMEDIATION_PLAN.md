## 1. Ревизия результатов аудита и ключевые принципы

Базовое предположение: проект ориентирован на развертывание на чистый сервер, однако оснащается **интеллектуальным инспектором предварительной проверки (Preflight Conflict Inspector & Resolver)**, который мягко разрешает конфликты с уже работающими службами (Dokploy, Traefik, Docker, systemd-resolved, сторонние сайты Nginx), не ломая хостовую систему.

В ходе независимой проверки результатов аудита с сопоставлением исходного кода `v7.3.4` и результатов прогона 34 проверок `audit_checks.py` (где 16 дефектов воспроизведены на стенде, 15 проверок пройдены, 1 не воспроизведена и 1 требует ревизии) были учтены следующие критические нюансы реализации:

1. **Затирание серверных ключей VLESS-REALITY и shortIds (`configure_3xui.sh:1453, 1782, 1800`):**
   В отличие от `update_repair.sh:702–725`, скрипт `configure_3xui.sh` не извлекает действующие ключи REALITY из базы данных. При каждом запуске вызывается `generate_reality_keypair()` и генерируются новые `shortIds`, что приводит к немедленной потере связи всеми клиентами VLESS-REALITY.
2. **Множественные деструктивные операции с клиентами (`configure_3xui.sh:1475–1481`):**
   Удаление разделено на три вызова: `client_inbounds`, `clients` и `client_traffics`. Блокировка удаления должна распространяться на все три таблицы, а агрессивный сбор реквизитов чужих клиентов (`L1416–1448`) должен быть отключен.
3. **Безопасное разрешение конфликтов без ломки хоста (Dokploy / Docker / Nginx / UFW):**
   - Отказ от `ufw --force reset` в пользу точечных правил `ufw allow`.
   - Отказ от удаления чужих сайтов Nginx (`rm -rf /etc/nginx/sites-enabled/*`) в пользу изоляции конфига в `/etc/nginx/conf.d/vpn_mask.conf`.
   - Интеллектуальный перенос порта AdGuard Home с 3000 на 3001/3053 при обнаружении Dokploy UI.
   - Деликатное переключение `DNSStubListener=no` для `systemd-resolved` на 53 порту.
4. **Консистентность WAL SQLite (`setup_mask.sh:3794`, `update_repair.sh:91`):**
   Файловое копирование `cp` не фиксирует страницы WAL при активном процессе. Решением является использование `sqlite3.Connection.backup()`.
5. **Совместимость Nginx HTTP/2 (`setup_mask.sh:4924`):**
   Директива `http2 on;` приводит к падению Nginx < 1.25.1 на стандартных пакетах Debian 11/12 и Ubuntu 20.04/22.04.

## 2. Архитектурный контракт и целевое состояние (/goal)

### Архитектура модуля разрешения конфликтов:
```text
[Инсталлятор] -> [Preflight Conflict Inspector (ss -tulpn)]
                      |
        +-------------+-------------+
        |                           |
  [Порты свободны]         [Обнаружен конфликт]
        |                           |
  [Штатный запуск]         [Интерактивный диалог / CLI-флаги]:
                           - Порт 3000 (AGH) -> Перенос на 3001
                           - Порт 53 -> DNSStubListener=no
                           - Порты 80/443 -> Четкая диагностика PID
                           - UFW -> Добавление правил без reset
                           - Nginx -> vpn_mask.conf без удаления чужих сайтов
```

### Фундаментальные принципы:
- **Zero Data Loss:** Полный запрет на автоматическое удаление клиентов и сброс ключей шифрования (REALITY, xHTTP).
- **ACID-развертывание:** Атомарные бэкапы через SQLite Backup API, сохранение манифеста изменений, автоматический `trap`-откат при сбоях.
- **Безопасность по умолчанию:** Права `0600` на закрытые SSL-ключи, санитизация клиентских имен в AmneziaWG против Path Traversal, закрытие DoH AGH через секретный ClientID.

## 3. Архитектурные ускорители (/boost)

| Компонент | Текущая проблема | Решение | Эффект |
|---|---|---|---|
| **Preflight Inspector** | Слепой захват портов и сброс UFW/Nginx | Инспектор портов на базе `ss -tulpn` с мягким разрешением | Совместимость с Dokploy, Docker и другими службами |
| **Reconcile Engine** | Дублирование 2500 строк в `configure_3xui.sh` и `update_repair.sh` | Единый Python-модуль `provisioner/reconcile.py` | Ликвидация расхождений и гарантия сохранности ключей |
| **SQLite Backup** | Потеря транзакций WAL при `cp` | Python SQLite Online Backup API | Гарантированная консистентность бэкапов |
| **Nginx Generator** | Падение Nginx при `http2 on;` | Шаблонизатор с определением версии Nginx | Совместимость с Debian 11/12 и Ubuntu 20.04/22.04/24.04 |
| **Xray Routing** | Ошибочная AND-логика для RU-трафика, перехват YouTube в WARP | Разделение правил на независимые OR-блоки с приоритетом YouTube | Корректный прямой выход для банков РФ и YouTube 4K |
| **AmneziaWG** | Двойная запись пиров при bind-mount, сброс блокировки при рестарте | Атомарная запись с `fcntl.flock`, персистентный статус `suspended` | Исключение дублей и стабильная блокировка |
