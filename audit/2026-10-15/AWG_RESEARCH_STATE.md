## Основные результаты B

- S>=12, включая12, проходит соответствующую проверку HPK. Ошибка EINVAL не является падением ядра; точная цитата диагностики в исходном отчёте неверна.
- CPS относится к1.5; название — Custom Protocol Signature. RandomTrailers влияет также на внутренний transport padding. KeepaliveTimeout не равен PersistentKeepalive, лимит попыток не удаляет peer.
- Tools v3.1.20260812 отвергает словесный false в.conf; использоватьoff/0. Для Go UAPI и JSON форматы другие.
- DNS-пример имеет44байта, включая2случайных, а не128. 42байта остаются постоянными. Вопрос о прохождении фильтрации передан C.
- Android v3.1.20260814 parser/backend поддерживает3.1, 2.0.1 parser отвергает поля3.x. Официальная нижняя граница AmneziaVPN3.1 —5.0.1.5. Для KeeneticOS4.2 документированAWG1.0, native3.1 — с5.2 Alpha11. AWGManager2.17.4 changelog подтверждает awg_proxy1.4.0.
- У проекта два разных backend: in-process AWG3X-UI (текущий upstreammain использует Go3.1.20260828/gVisor) и Docker-adapter manage_amneziawg.py. Нельзя считать их настройки/клиентскую выдачу синхронизированными.
- В Docker-adapter серверный RandomTrailers не читается, а четыре клиентских представления hardcode on; fallbackHPK может генерироваться без применения на сервере. Слепая смена этих строк наoff не решает согласование с реальным сервером.
- DNS ошибка подтверждена, но есть и другие hardcodeDNS. Host/container MSS clamp уже реализованы; host persistence может пропускаться при уже существующей mangleтаблице. Применимость к embeddednetstack требует C.
- P28 на A был извлечён неточно: исходник называет S16/20/24/16 стандартом проекта, а не официальным стандартомAWG. В реестре исправлено; набор действительно есть в template панели.
