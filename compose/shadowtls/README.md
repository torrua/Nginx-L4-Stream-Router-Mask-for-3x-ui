# ShadowTLS v4 + Shadowsocks-2022 (with udp_over_tcp)

Связка **ShadowTLS v4** и **Shadowsocks-2022** представляет собой одну из самых криптостойких и скрытных архитектур обхода DPI:

### Принцип работы
1. **Подлинное TLS-рукопожатие**: ShadowTLS не генерирует самоподписанные сертификаты, а напрямую проксирует рукопожатие к легитимному целевому серверу (`gateway.icloud.com`).
2. **Аутентификация через HMAC**: Клиент внедряет криптографическую метку в сессионный билет TLS. Если пароль верный — сессия перехватывается и передаётся локальному Shadowsocks-2022 бэкенду.
3. **Защита от активных зондов (Active Probing Defense)**: Если к серверу подключается цензор или сетевой сканер (Censys, Shodan, РКН DPI) без знания HMAC-пароля, ShadowTLS бесшовно проксирует соединение к `gateway.icloud.com:443`. Сканер видит настоящий сервер Apple!
4. **Инкапсуляция UDP-over-TCP (`udp_over_tcp: true`)**: Весь UDP-трафик (DNS, игры, WebRTC) упаковывается внутрь TCP-соединения Shadowsocks, исключая блокировки UDP у мобильных операторов.

### Запуск
```bash
docker compose -f ../docker-compose.nextgen.yml up -d shadow-tls
```
