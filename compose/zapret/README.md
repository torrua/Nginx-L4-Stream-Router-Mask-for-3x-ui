# Server-Side Zapret (nfqws with iptables connbytes 1:6)

Серверный модуль **Zapret** (`nfqws`) десинхронизирует DPI операторов связи и ТСПУ непосредственно на стороне VPS, предотвращая разрывы соединений (RST-инъекции) и блокировки TLS-рукопожатий.

### Архитектурный механизм `connbytes 1:6`
- **Высокая скорость (Wire Speed)**: Правило iptables перехватывает в очередь NFQUEUE только первые **6 пакетов** TCP-сессии (`--connbytes 1:6 --connbytes-mode packets`): SYN/ACK и обмен ClientHello/ServerHello.
- **Нулевая нагрузка на стриминг**: Весь основной полезный трафик (фильмы, загрузки, данные) идёт напрямую на уровне ядра Linux без участия очереди NFQUEUE.
- **Отказоустойчивость `--queue-bypass`**: Если контейнер `zapret` останавливается или перезапускается, пакеты не отбрасываются ядром.
- **Методы десинхронизации**:
  - `--dpi-desync=split2`: расщепление первого пакета данных TLS ServerHello.
  - `--dpi-desync-fooling=md5sig,badseq`: инъекция фейковых сегментов с некорректной TCP-последовательностью или MD5-сигнатурой, вводящей ТСПУ в заблуждение.

### Запуск
```bash
docker compose -f ../docker-compose.nextgen.yml up -d server-side-zapret
```
