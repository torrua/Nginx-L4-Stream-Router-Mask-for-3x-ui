# 🚀 Пошаговое руководство: Настройка личного VPN с нуля

Это руководство написано простым языком для тех, кто никогда раньше не настраивал серверы. Весь процесс занимает около 15–20 минут.

---

## 🧭 Как это работает

Обычные VPN (OpenVPN, чистый WireGuard) легко блокируются операторами по структуре пакетов.

В этом решении защита строится так:
1. **Снаружи сервер выглядит как обычный сайт.** У него есть настоящий SSL-сертификат, и в браузере открывается страница компании.
2. **Все запросы идут на порт 443.** Это стандартный порт для защищённых сайтов (HTTPS). Для провайдера это выглядит как обычный просмотр веб-страниц.
3. **Nginx распределяет подключения:**
   * Сканеры цензоров и обычные браузеры видят только сайт.
   * Ваше приложение с секретным ключом сразу получает доступ в интернет.

## 📋 Что нужно подготовить до старта

Вам понадобятся две вещи:

### 1. Сервер (VPS)
* **Что это:** удалённый компьютер, который работает круглосуточно в дата-центре. Стоит обычно от 150 до 400 рублей в месяц.
* **Где арендовать:** любой хостинг (Aeza, PQ Hosting, Hetzner, VDSina, FirstByte и др.).
* **Где разместить:** выбирайте страны ближе к вам (Германия, Нидерланды, Финляндия, Турция, Казахстан) — пинг будет ниже.
* **Характеристики сервера:**
  * 1 процессор (vCPU);
  * 1–2 ГБ оперативной памяти (RAM);
  * 10–20 ГБ диска (SSD);
  * Операционная система: **Ubuntu 22.04** или **Ubuntu 24.04** (также подойдёт Debian 11/12).
* После оплаты хостинг выдаст вам **IP-адрес сервера** и **пароль root** (или SSH-ключ).

---

### 2. Доменное имя

* **Зачем домен:** чтобы выпустить настоящий бесплатный SSL-сертификат (Let's Encrypt), серверу нужно доменное имя.
* **Где купить:** у любого регистратора (Reg.ru, Beget, Namecheap, Spaceship и др.). Подойдут самые дешёвые зоны: `.site`, `.online`, `.tech`, `.ru` (часто по 100–200 рублей).
* **Как привязать к серверу:**
  * В панели управления доменом (или в [Cloudflare](https://dash.cloudflare.com/)) добавьте **A-запись**:
    * **Имя (Name):** `@` (или поддомен, например `vpn`).
    * **Значение (IP):** IP-адрес вашего купленного сервера.

> [!CAUTION]
> ### ⚠️ Важно, если используете Cloudflare («Серое облако»)
> В строке A-записи в Cloudflare статус обязательно должен быть **DNS Only (Серое облако)**.  
> Если оставить оранжевое облако (Proxied), Cloudflare пропустит трафик через свои фильтры, и VPN работать не сможет.

#### А можно выпустить сертификат прямо на IP-адрес (без домена)?
* **Технически — да.** Сервисы вроде ZeroSSL и Let's Encrypt уже умеют выдавать SSL-сертификаты на публичные IP-адреса.
* **Но почему домен всё равно нужен здесь:** веб-сервер Nginx слушает один порт 443 и разделяет сервисы по имени домена (технология SNI). По домену Nginx понимает: это запрос к сайту, к панели управления или к VPN. Если домена нет, разделить несколько служб на одном порту 443 не получится. Поэтому домен остаётся обязательным.

## 💻 Шаг 1. Подключение к серверу по SSH

### С компьютера на Windows (10 или 11):
1. Нажмите сочетание клавиш `Win + R`, наберите `powershell` (или `cmd`) и нажмите **Enter**.
2. Введите команду:
   ```bash
   ssh root@IP_ВАШЕГО_СЕРВЕРА
   ```
   *(замените `IP_ВАШЕГО_СЕРВЕРА` на реальный IP от хостинга)*.
3. Если спросят `Are you sure you want to continue connecting?` — наберите **`yes`** и нажмите **Enter**.
4. Введите пароль пользователя `root` и нажмите **Enter**.  
   *Обратите внимание: при вводе пароля символы и звёздочки на экране не показываются. Это стандартная мера безопасности в Linux — просто наберите пароль и нажмите Enter.*

### С компьютера на macOS или Linux:
* Откройте стандартный **Терминал**, введите `ssh root@IP_ВАШЕГО_СЕРВЕРА` и введите пароль.

### С телефона (iOS / Android):
* Установите бесплатное приложение **Termius**, добавьте новый хост, укажите IP, логин `root` и пароль.

## 🛠️ Шаг 2. Запуск мастера установки

После входа на сервер вставьте эту команду и нажмите **Enter**:

```bash
curl -sSL https://raw.githubusercontent.com/torrua/Nginx-L4-Stream-Router-Mask-for-3x-ui/main/setup_mask.sh | sudo bash
```

### Вопросы установщика:
1. **`Enter your main domain`:** введите ваш домен, направленный на IP сервера (например: `myserver.online`).
2. **`Enter email for Let's Encrypt`:** укажите ваш email (нужен центру сертификации для уведомлений о продлении).
3. **`Enter secret path for 3X-UI`:** придумайте секретное слово для адреса админки (например: `myadminpanel`).
4. **`Enter subscription path`:** придумайте слово для ссылки с подписками (например: `subkeys`).
5. **`Select Decoy Site`:** выберите сайт-маскировку (нажмите `1` — DataSphere Analytics, красивый сайт IT-сервиса).
6. **`AdGuard Home`:** опциональный блокировщик рекламы и трекеров (для быстрого старта можно нажать `n`).

Скрипт автоматически установит Nginx, выпустит сертификат, настроит защиту и установит панель 3X-UI.  
В конце на экране появится зелёная рамка с адресом панели, логином и паролем. **Сохраните их!**

## 🎛️ Шаг 3. Автоматическая настройка подключений

Чтобы не настраивать протоколы вручную в панели, запустите утилиту автонастройки:

```bash
curl -sSL https://raw.githubusercontent.com/torrua/Nginx-L4-Stream-Router-Mask-for-3x-ui/main/configure_3xui.sh | sudo bash
```

Скрипт сам создаст в панели лучшие подключения:
* **AmneziaWG:** оптимизирован для сотовых операторов РФ (МТС, Билайн, Мегафон, Т2) — шум в пакетах, MTU 1280, ёмкость до 1022 клиентов, DNS от Control D.
* **VLESS Reality:** скоростное подключение для дома и офиса без потери скорости.
* **VLESS xHTTP:** подключение через чистый HTTP/2 для сетей с жёсткой фильтрацией.

## 📱 Шаг 4. Подключение устройств

### 1. Откройте панель в браузере
Перейдите по адресу:  
`https://ваш-домен/ваш_секретный_путь/` *(обязательно со слэшем `/` в конце!)*  
Войдите под выданным логином и паролем.

### 2. Получите ссылку или QR-код
* Откройте раздел **«Подключения»** (Inbounds).
* Напротив нужного подключения нажмите значок **«+»** (добавить клиента) и сохраните.
* Нажмите значок **QR-кода** рядом с именем пользователя или скопируйте ссылку `vless://...`.

### 3. Настройка приложений

| Устройство | Приложения | Как включить |
| :--- | :--- | :--- |
| **iPhone / iPad** | **Happ Proxy** (лучший выбор), **FoXray**, **Streisand** | Открыть приложение → нажать «+» → «Сканировать QR-код» → включить туннель. |
| **Android** | **v2rayNG**, **Happ Proxy**, **NekoBox** | Нажать «+» → «Импорт из буфера обмена» или отсканировать QR-код → нажать кнопку старта. |
| **Windows** | **v2rayN**, **Happ**, **Flclash** | Скопировать ссылку → вставить в программу (`Ctrl + V`) → включить «Системный прокси». |
| **macOS** | **FoXray**, **V2RayXS**, **Karing** | Добавить подключение по ссылке или QR-коду. |
| **Роутеры Keenetic** | Встроенный клиент WireGuard / AmneziaWG | В панели 3X-UI скачать `.conf` файл для AmneziaWG и загрузить в меню роутера «Другие подключения». |

## 💡 Какой протокол когда использовать

* 📱 **На телефоне в сотовой сети:** используйте **AmneziaWG** или **VLESS Reality**. Они стабильно держат связь при смене вышек и обходят фильтрацию.
* 🏠 **Дома на Wi-Fi и на компьютере:** используйте **VLESS Reality**. Даёт скорость до 1 Гбит/с и почти не расходует батарею.
* 🛡️ **Если интернет глушат или в строгих сетях:** используйте **VLESS xHTTP**.

## ❓ Решение частых вопросов (FAQ)

#### Сайт открывается, а панель выдаёт ошибку 404?
* Проверьте адрес: в конце обязательно должен быть слэш: `https://домен/секретный_путь/`. Без слэша веб-сервер отклоняет запрос для безопасности.

#### В приложении пишет «Пинг: N/A» или не открываются сайты?
1. Проверьте Cloudflare: проксирование должно быть выключено (**только серое облако**).
2. Проверьте хостинг: в личном кабинете должны быть открыты порты `80/TCP`, `443/TCP`, `443/UDP`.
3. Для VLESS xHTTP поле `Flow` должно быть пустым (`none`).
