# 🚀 Релиз v7.6.0: Оптимизация AmneziaWG 3.1, безопасность и надёжность

В этом обновлении оптимизирована работа протокола **AmneziaWG 3.1** в панели 3X-UI для устойчивого обхода блокировок, устранена просадка скорости, а также закрыты ключевые задачи безопасности и стабильности системных сервисов (Nginx, SQLite, AdGuard Home).

---

## 💡 Главное в релизе простыми словами

1. **Скорость и стабильность AmneziaWG 3.1 в 3X-UI**:
   - **Устранено падение скорости**: отключен ресурсоёмкий параметр случайных хвостов пакетов (`randomTrailers`), из-за которого процессор перегружался и скорость падала до 2–5 Мбит/с.
   - **Стабильное соединение без обрывов**: скорректированы интервалы обновления ключей шифрования (`rekeyAfterTime = 120-170`), устранив конфликт пересечения таймингов в валидаторе 3X-UI.
   - **Безопасные параметры маскировки**: скорректированы размеры случайного шума (паддинги $S_1-S_4$: `16, 20, 24, 16`) для надёжной инициализации на всех клиентских устройствах.
   - **Сохранение настроек**: при обновлении скриптом `update_repair.sh` или аудите базы действующие тайминги и сигнатурные шаблоны $I_1-I_5$ больше не сбрасываются.

2. **Безопасность и защита данных**:
   - **Надёжные резервные копии**: сохранение базы данных 3X-UI теперь выполняется транзакционно с обязательной проверкой целостности данных SQLite WAL (`PRAGMA integrity_check`).
   - **Изоляция служебных процессов**: веб-сервер Nginx переведён на быстрые локальные сокеты в оперативной памяти (`/dev/shm`), что исключает сетевые конфликты.
   - **Защита системного окружения**: команды интерактивного спиннера изолированы в subshell, предотвращая случайное изменение глобальных переменных оболочки.
   - **Резервирование портов**: порт 3000 закреплен за собственной службой AdGuard Home.

3. **Качество и автоматические тесты**:
   - В систему непрерывной интеграции (CI) проекта добавлен регрессионный тестовый пакет: автоматические тесты проверяют целостность базы данных, корректность таймингов и бесконфликтность портов.

## 🛠️ Технические подробности для администраторов

### Протокол AmneziaWG 3.1 в 3X-UI
* **randomTrailers = false**: побайтовое добавление случайных данных в конец каждого сетевого пакета вызывало блокировку памяти ядра и деградацию single-thread производительности Go-стека. Параметр отключен по умолчанию.
* **Синхронизация таймингов**: встроенный валидатор 3X-UI требует выполнения условия `max(rekeyAfterTime) < min(rejectAfterTime)`. Зафиксированы безопасные непересекающиеся диапазоны:
  - `rekeyAfterTime = 120-170` сек.
  - `rekeyTimeout = 3-4` сек.
  - `rejectAfterTime = 180-210` сек.
  - `keepaliveTimeout = 15-20` сек.
  - `maxHandshakeAttempts = 20-25`.
* **Smart Reconcile**: при обновлении конфигураций инбаундов сохранены все параметры таймингов и CPS-шаблоны `i1`–`i5`.
* **Паддинги**: для смещений мусорных пакетов установлены безопасные значения `S1=16, S2=20, S3=24, S4=16` ($S_1 \ge 12$ для `HeaderProtectionKey`, $S_1 + 56 \neq S_2$).

### Безопасность и системный стек
* **Nginx Unix Sockets & Preflight**: Внутренние прокси-хосты Nginx переведены на Unix-сокеты. Preflight прерывает установку, если внешний порт 443 занят сторонней службой.
* **SQLite WAL Integrity**: Резервные копии SQLite создаются транзакционно через `sqlite3 .backup` после сброса WAL-журнала с обязательной валидацией `PRAGMA integrity_check`.
* **Subshell Spinner Isolation**: Запуск фоновых задач внутри спиннера вынесен в изолированный подоболочечный контекст (`subshell`), предотвращая повреждение глобальных переменных окружения и дескрипторов ввода-вывода.
* **Routing Normalization**: Движок маршрутизации Xray нормализует раздельные списки доменов и IP для России, сохраняя кастомные подсети пользователей.
* **AdGuard Home Port Reservation**: Порт 3000 закреплен за собственной службой AdGuard Home.
