# 🚀 Релиз v7.6.0: Оптимизация AmneziaWG 3.1, безопасность и надёжность

В этом обновлении мы оптимизировали работу протокола **AmneziaWG 3.1** для обхода блокировок, устранили причину просадки скорости, а также закрыли все замечания по безопасности и стабильности (аудит R01–R09).

---

## 💡 Главное в релизе простыми словами

1. **Скорость и стабильность AmneziaWG**:
   - **Устранено падение скорости**: отключен ресурсоёмкий параметр случайных хвостов пакетов (`RandomTrailers`), из-за которого процессор перегружался и скорость падала до 2–5 Мбит/с.
   - **Стабильное соединение без обрывов**: скорректированы интервалы обновления ключей шифрования (`RekeyAfterTime`), что устранило конфликты в фоновом сервисе 3X-UI.
   - **Корректные адреса DNS**: исправлена подстановка серверов DNS (`9.9.9.9` и `76.76.2.0`) во всех создаваемых конфигурациях клиентов.
   - **Безопасные параметры маскировки**: скорректированы размеры случайного шума (паддинги $S_1-S_4$) для надежного запуска на всех поддерживаемых устройствах.

2. **Безопасность и защита данных**:
   - **Надежные резервные копии**: сохранение базы данных 3X-UI теперь выполняется с обязательной проверкой целостности данных.
   - **Мгновенная блокировка клиентов**: при блокировке пользователя в панели его доступ к туннелю AmneziaWG немедленно отключается на уровне сервера.
   - **Изоляция служебных процессов**: веб-сервер Nginx переведён на быстрые локальные сокеты в оперативной памяти (`/dev/shm`), что исключает сетевые конфликты.
   - **Безопасные имена и пути**: добавлена фильтрация недопустимых символов в именах клиентов для защиты файловой системы сервера.

3. **Качество и автоматические тесты**:
   - В систему проверки проекта добавлен регрессионный тестовый пакет: все 17 системных тестов пройдены успешно.

## 🛠️ Технические подробности для администраторов

### Протокол AmneziaWG 3.1
* **RandomTrailers = off**: побайтовое добавление случайных данных в конец каждого сетевого пакета вызывало блокировку памяти ядра и деградацию single-thread производительности. Параметр отключен по умолчанию.
* **Синхронизация таймингов**: валидатор 3X-UI требует выполнения условия `max(RekeyAfterTime) < min(RejectAfterTime)`. Зафиксированы непересекающиеся диапазоны:
  - `RekeyAfterTime = 120-170` сек.
  - `RekeyTimeout = 3-4` сек.
  - `RejectAfterTime = 180-210` сек.
  - `KeepaliveTimeout = 15-20` сек.
  - `MaxHandshakeAttempts = 20-25`.
* **Smart Reconcile**: при обновлении конфигураций инбаундов сохранены все параметры таймингов и CPS-шаблоны `i1`–`i5`.
* **Паддинги**: для смещений мусорных пакетов установлены безопасные значения `S1=16, S2=20, S3=24, S4=16` ($S_1 \ge 12$ для `HeaderProtectionKey`, $S_1 + 56 \neq S_2$).

### Безопасность и системный стек (Аудит R01–R09)
* **R01**: Внутренние прокси-хосты Nginx переведены на Unix-сокеты. Preflight прерывает установку, если внешний порт 443 занят сторонней службой.
* **R02**: Имена клиентов валидируются регулярным выражением, исключена уязвимость выхода за пределы каталога (path traversal).
* **R03**: При блокировке пира секция `[Peer]` удаляется из конфигурации `awg0.conf` и рантайма ядра Linux. При разблокировке — восстанавливается.
* **R04**: Резервные копии SQLite создаются транзакционно через `sqlite3 .backup` с валидацией `PRAGMA integrity_check`.
* **R05**: Ошибки записи конфигураций AWG перехватываются с откатом предыдущего состояния.
* **R06**: Запуск задач спиннера изолирован в subshell, что защищает глобальные переменные окружения.
* **R07**: Правила маршрутизации для доменов и IP России сохраняют кастомные подсети пользователей.
* **R08**: Набор тестов `tests/test_audit_regressions.py` интегрирован в репозиторий и CI.
* **R09**: Порт 3000 закреплен за собственной службой AdGuard Home.
