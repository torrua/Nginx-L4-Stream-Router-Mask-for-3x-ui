# 🚀 Релиз v7.6.0: Оптимизация AmneziaWG 3.1, безопасность и устранение находок аудита R01–R09

Этот релиз объединяет результаты всестороннего исследования протокола **AmneziaWG 3.1** в условиях глубокого анализа трафика (ТСПУ/DPI), критические оптимизации производительности сетевого стека, а также исправление всех находок аудита безопасности от 15 октября 2026 года (R01–R09).

---

## 🌟 Главные вехи релиза
1. **Глубокая оптимизация AmneziaWG 3.1 против блокировок**:
   - Отключение деградирующего параметра `RandomTrailers = off` (предотвращение критического падения скорости в 100–300 раз из-за single-thread блокировок памяти).
   - Коррекция граничных условий таймингов в валидаторе 3X-UI: `RekeyAfterTime = 120-170` при `RejectAfterTime = 180-210` (строгое выполнение инварианта `max(rekey) < min(reject)`).
   - Безопасные смещения мусора $S_1-S_4$: гарантированное выполнение условия $S_1 \ge 12$ для `HeaderProtectionKey` и $S_1 + 56 \neq S_2$.
   - Исправление ошибки подстановки системных переменных DNS (`$PRIMARY_DNS` -> `9.9.9.9`, `76.76.2.0`) во всех точках генерации клиентов, конфигураций и URI.
2. **Устранение находок аудита безопасности (R01–R09)**:
   - Полная изоляция виртуальных хостов Nginx на Unix domain sockets в `/dev/shm`.
   - Защита от инъекций путей (path traversal) и валидация идентификаторов клиентов в AmneziaWG.
   - Корректное удаление и восстановление заблокированных пиров в `awg0.conf`.
   - Транзакционные и верифицируемые резервные копии SQLite WAL с `PRAGMA integrity_check`.
   - Автоматический откат состояния при сбоях записи в runtime-файлы AWG.
   - Изоляция команд спиннера в subshell для сохранения глобального контекста оболочки.
   - Защита кастомных масок и подсетей при нормализации правил маршрутизации RU-трафика.
   - Резервирование порта 3000 для собственного сервиса AdGuard Home.
3. **Регрессионное тестирование (`tests/test_audit_regressions.py`)**:
   - Полноценный набор модульных assert-тестов, проверяющий все критические инварианты сетевых протоколов и безопасности.

## ⚡ Оптимизация AmneziaWG 3.1 и защита от ТСПУ

* **Ликвидация узкого места по CPU (`RandomTrailers = off`)**:
  - Параметр `RandomTrailers` добавляет случайные байты в конец каждого пакета данных. В ядре Linux и Go-девайсе это приводило к постоянной переаллокации буферов `sk_buff` в одном потоке, снижая пропускную способность гигабитного канала до 2–5 Мбит/с. Параметр переведен в статус `off` по умолчанию.
* **Строгое согласование таймингов ротации ключей**:
  - Валидатор Go-стека 3X-UI завершает работу с ошибкой при пересечении времени пересогласования ключей и сброса сессии. Установлены безопасные диапазоны: `RekeyAfterTime = 120-170`, `RekeyTimeout = 3-4`, `RejectAfterTime = 180-210`, `KeepaliveTimeout = 15-20`, `MaxHandshakeAttempts = 20-25`.
* **Защита Smart Reconcile Engine**:
  - При повторных запусках `configure_3xui.sh` и `update_repair.sh` модуль сверки инбаундов автоматически сохраняет пользовательские тайминги и CPS-шаблоны `i1`–`i5`, не сбрасывая их к базовым значениям.
* **Синхронизация DNS-серверов**:
  - Устранена опечатка с буквальной подстановкой имени переменной `$PRIMARY_DNS`. Клиентские файлы конфигураций `.conf`, ссылки `vpn://` и таблица пиров теперь содержат валидные резолверы Quad9 (`9.9.9.9`) и Control D (`76.76.2.0`).

## 🛡️ Безопасность и отказоустойчивость (Аудит R01–R09)

* **R01 (Nginx Unix Sockets & Preflight)**:
  - Все внутренние прокси-хосты Nginx адаптированы для взаимодействия через локальные Unix-сокеты. Preflight-инспектор прерывает установку при обнаружении стороннего процесса на внешнем порту 443.
* **R02 (AWG Client Sanitization)**:
  - Имена клиентов и идентификаторы очищаются от спецсимволов. Заблокирован выход за пределы рабочего каталога `AWG_DIR` через относительные пути (`..`).
* **R03 (AWG Block/Unblock)**:
  - При блокировке клиента секция `[Peer]` атомарно удаляется из `awg0.conf` и интерфейса `awg set`, исключая несанкционированный доступ по активным сессиям. При разблокировке пир корректно восстанавливается.
* **R04 (SQLite WAL Integrity)**:
  - Устранено небезопасное прямое копирование базы данных (`cp`). Бэкап выполняется строго через `sqlite3 .backup` после сброса WAL-журнала, с обязательной проверкой контрольной суммы и целостности таблицы.
* **R05 (Atomic AWG Write & Rollback)**:
  - Любой сбой записи в конфигурации AmneziaWG вызывает исключение `IOError` с восстановлением предыдущего снапшота состояния.
* **R06 (Subshell Spinner Isolation)**:
  - Выполнение фоновых задач внутри спиннера вынесено в изолированный подоболочечный контекст (`subshell`), предотвращая повреждение глобальных переменных окружения и дескрипторов ввода-вывода.
* **R07 (Routing Normalization)**:
  - Движок маршрутизации Xray нормализует раздельные списки доменов и IP для России, аккуратно сохраняя пользовательские подсети и исключения.
* **R08 (Regression Test Suite)**:
  - Набор тестов `tests/test_audit_regressions.py` включен в конвейер непрерывной интеграции (CI).
* **R09 (AdGuard Home Port Reservation)**:
  - Порт 3000 закреплен за собственной службой AdGuard Home; логика поиска свободных портов предотвращает коллизии и конфликты с веб-панелью.
