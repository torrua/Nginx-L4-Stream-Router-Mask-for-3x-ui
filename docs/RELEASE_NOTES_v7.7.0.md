# 🚀 Релиз v7.7.0: Архитектурный апгрейд AmneziaWG 3.1, клиентские пресеты и Zero-Downtime управление

В релизе **v7.7.0** представлена обновленная архитектура управления протоколом **AmneziaWG 3.1**, добавлена система готовых клиентских пресетов в CLI-контроллере (`awg-cli`), подтверждена высокая производительность протокола при включенной защите `RandomTrailers`, а также выпущено подробное руководство по настройке всех типов клиентских устройств.

---

## 💡 Главное в релизе простыми словами

1. **Архитектура «Единый сервер — гибкие клиенты»**:
   * Серверная конфигурация настраивается один раз и остаётся неизменной: криптографический каркас (`HPK`, `S1..S4`, `H1..H4`, `RandomTrailers`, `MTU = 1280`) зафиксирован на уровне ядра интерфейса `awg0`.
   * Клиентам можно выдавать совершенно разные профили под их задачи и сети без изменения настроек сервера и без перезагрузки служб.

2. **Готовые пресеты генерации в `awg-cli`**:
   * **`--preset=stealth` (Мобильный / Анти-DPI)**: включает 44-байтный DNS CPS-префикс `I1` (эмуляция ответа DNS), 4 мусорных пакета (`Jc=4, Jmin=40, Jmax=70`) и `MTU=1280`. Обеспечивает минимальный и стабильный пинг на сотовых операторах без блокировок DPI.
   * **`--preset=fast` (Домашний / Быстрый)**: отключает отправку мусора (`Jc=0`) и CPS-префикс, поднимая `MTU=1360`. Обеспечивает мгновенный отклик первого пакета и нулевую нагрузку на процессор домашних роутеров (Keenetic, OpenWrt) и Smart TV.
   * **`--preset=base` (Стандартный)**: классический сбалансированный профиль AmneziaWG 3.1 (`Jc=4`, без `I1`, `MTU=1280`).

3. **Опровержение мифа о падении скорости при `RandomTrailers`**:
   * Практические полевые испытания на сотовых сетях и домашнем Wi-Fi подтвердили: включенный режим `RandomTrailers = on` при согласованных смещениях ($S_1=S_2=S_3=S_4=12/16$) и скалярных заголовках ($H_1..H_4=1..4$) не создает деградации канала и обеспечивает полную пропускную способность линии (вплоть до 70+ Мбит/с на приём и отдачу).

4. **100% синхронизация `.conf` и `vpn://` (Single Source of Truth)**:
   * Генератор ссылок и QR-кодов считывает параметры (`MTU`, `Jc`, `Jmin`, `Jmax`, `I1`, `Keepalive`) напрямую из итогового `.conf`. Мобильное приложение Amnezia VPN при сканировании QR-кода гарантированно получает те же параметры, что и файл конфигурации.

5. **Новое руководство по настройке клиентов**:
   * Опубликовано исчерпывающее руководство [**`docs/AWG_CLIENT_CONFIGURATION_GUIDE.md`**](AWG_CLIENT_CONFIGURATION_GUIDE.md) с пошаговыми инструкциями для iOS, Android, Windows, macOS, Linux, Keenetic и OpenWrt, а также матрицей диагностики неполадок.

## 🛠️ Технические подробности для администраторов

### AmneziaWG 3.1 Controller & Engine
* **Сетевой стек и MTU ядра**: Серверный интерфейс `awg0` фиксируется на `MTU = 1280`. В сочетании с правилом iptables `TCPMSS --clamp-mss-to-pmtu` это гарантирует, что исходящие от сервера пакеты (Download) никогда не превысят безопасный предел и не вызовут фрагментацию или Blackhole MTU на сотовых вышках.
* **DNS CPS-эмуляция (`I1`)**: В контроллер встроен валидированный шаблон DNS-ответа (`<r 2><b 0x858000010001000000000669636c6f756403636f6d0000010001c00c000100010000105a00044d583737>`). Отправка префикса перед хэндшейком предотвращает пенализацию сессии DPI-фильтрами операторов.
* **Расширенные CLI-флаги в `awg-cli add`**:
  - `--preset=<stealth|fast|base>` — выбор базового сценария;
  - `--i1=dns` / `--no-i1` / `--i1="<pattern>"` — управление префиксом;
  - `--mtu=<1240|1280|1360>` — точечная подгонка MTU;
  - `--jc=<0..128>`, `--jmin=<N>`, `--jmax=<N>` — управление мусорными пакетами;
  - `--keepalive=<N>` — интервал сохранения NAT (по умолчанию 25 сек);
  - `--allowed-ips=<IPs>` — гибкая маршрутизация туннеля;
  - `--dns=<provider|IP>` — выбор DNS (Cloudflare, Quad9, Google, AdGuard);
  - `--qr` / `-q` — вывод графического ASCII QR-кода прямо в терминал.
* **Zero-Downtime синхронизация**: Все операции добавления и удаления пиров выполняются через UAPI ядра (`awg set awg0 peer ...`) без перезапуска сетевого интерфейса и без разрыва сессий активных пользователей.
