## 🐛 Исправленные проблемы (Bugfixes & Stability)

### 1. Каскадный «водопад» строк и сбои навигации в меню выбора протоколов (Шаг 5/12)
* **Симптомы:**  
  В интерактивном мастере установки [`setup_mask.sh`](../setup_mask.sh) на **Шаге 5/12: Выбор протоколов и транспортов (VPN / Прокси)** при попытке выбора протоколов в терминалах SSH (PuTTY, Windows Terminal, мобильные клиенты Termius):
  - Меню начинало циклически дублироваться вниз по экрану («водопад» из строк `[1] Hysteria 2`, `[2] AmneziaWG`), засоряя терминал;
  - Стрелки клавиатуры залипали или распадались на отдельные символы;
  - Нажатие стрелки «Вниз» (`\x1b[B`) из-за задержки сети распадалось, и символ `B` ошибочно воспринимался скриптом как команда «Назад» (`b - назад`), откатывая установщик обратно на Шаг 4.

* **Первопричины:**
  1. **Превышение ширины 80 колонок:** Тексты вариантов выбора (включая подсказки и описания протоколов) достигали 86–87 символов в одной строке. На стандартных терминалах шириной 80 символов строка автоматически переносилась. В то же время escape-последовательность `\033[%dA\r` поднимала курсор ровно на 8 физических строк, игнорируя перенесённые строки, что вызывало прогрессирующий сдвиг вниз на 2–3 строки при каждом нажатии клавиши.
  2. **Скролл буфера экрана:** При запуске скрипта в нижней части окна терминала ANSI-команда подъема курсора не может выйти за пределы видимой строки 1, вызывая лавинообразное смещение вывода.
  3. **Слишком короткий таймаут чтения escape-последовательностей (50 мс):** Конструкция `read -rsn2 -t 0.05` при сетевых задержках SSH разбивала 3-байтовую последовательность стрелки `\x1b[B`: в буфер попадал отдельный символ `B`, который немедленно триггерил условие `elif [[ "$key" == "b" || "$key" == "B" ]]` (возврат на предыдущий шаг).

* **Решение:**
  1. **Надёжный нумерованный селектор по умолчанию:** В [`src/tui/prompts.sh`](../src/tui/prompts.sh) функция `prompt_multiselect` переведена на строчный нумерованный режим ввода (`prompt_multiselect_numeric`). Список протоколов выводится один раз с наглядными чекбоксами `[✔]` и `[ ]`, а строка ввода предлагает готовый рекомендованный набор по умолчанию. Пользователю достаточно нажать **Enter** для применения рекомендаций, либо ввести номера нужных протоколов.
  2. **Ограничение длины строк:** В [`src/tui/wizard.sh`](../src/tui/wizard.sh) описания протоколов сокращены до строго менее чем 68 символов, гарантируя идеальное отображение без переносов даже на экранах шириной 70–80 колонок.
  3. **Защита от распада ANSI-последовательностей:** Таймаут чтения escape-кодов увеличен с 50 мс до 200 мс (`-t 0.2`), а обработчик клавиши `b` изолирован от остаточных фрагментов стрелок.

### 2. Поддержка разделения номеров пробелами (`1 2 4`)
* **Проблема:**  
  В функции `prompt_multiselect_numeric` выражение `tr -d '[:space:]'` удаляло все пробелы перед разбором токенов. Если пользователь вводил `1 2 4` через пробел, строка склеивалась в `124`, приводя к ошибке «Неверный номер: 124».
* **Исправление:**  
  Удаление пробелов заменено на корректный парсер токенов: теперь одинаково надёжно работают как ввод через запятую (`1,2,4`), так и ввод через пробел (`1 2 4`), а также их комбинации (`1, 2, 4`).

## 📋 Инструкция по обновлению на сервере

Для запуска обновленного мастера установки выполните:

```bash
curl -sSL "https://raw.githubusercontent.com/torrua/Nginx-L4-Stream-Router-Mask-for-3x-ui/main/install.sh?v=$(date +%s)" | sudo bash
```

Или при прямом запуске `setup_mask.sh`:

```bash
curl -sSLO "https://raw.githubusercontent.com/torrua/Nginx-L4-Stream-Router-Mask-for-3x-ui/main/setup_mask.sh" && sudo bash setup_mask.sh
```
