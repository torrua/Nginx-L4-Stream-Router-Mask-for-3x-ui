## 🚀 Основные нововведения релиза v8.1.0

### 1. Подсистема безопасности хоста (Host Security & SSH Hardening)
Перенесен и расширен полный комплекс защитных механизмов из `secure-vps.sh` непосредственно в единый мастер установки ([`setup_mask.sh`](../setup_mask.sh)), Экспресс-инсталлятор ([`install.sh`](../install.sh)) и конфигурацию окружения (`.env`):

* **Безопасный двухпортовый переход SSH (Zero-Risk Dual-Port Transition):**
  - При смене порта SSH служба `sshd` переводится в режим параллельного прослушивания **обоих портов** (нового и активного) через drop-in конфигурацию `/etc/ssh/sshd_config.d/99-hardening.conf`.
  - В UFW открываются оба порта.
  - Fail2ban защищает оба порта одновременно (`port = <старый>,<новый>`).
  - Перед финализацией выполняется локальный зонд чтения SSH-баннера (`SSH-2.0-...`) через `/dev/tcp/127.0.0.1/<порт>`. При любой ошибке демон откатывается на исходный порт без потери связи.
* **Автоматическое закрытие старого порта (Live Handshake & Watcher):**
  - **В интерактивном режиме:** скрипт выводит IP-адрес и команду для проверки в новой вкладке (`ssh -p <порт> root@<IP>`), отслеживая сокеты ядра (`ss -tn sport = :<порт> state established`). При входе старый порт 22 немедленно закрывается.
  - **В автоматическом / фоновом режиме (CI / тихий режим / .env):** развертывается автономный systemd-сервис `ssh-transition-watcher.service` (`/usr/local/bin/ssh-transition-watcher.sh`). Он тихо ожидает первого внешнего подключения на новый порт, после чего автоматически вырезает старый порт из конфигурации, удаляет правило UFW, обновляет Fail2ban и самоудаляется.
* **Управление SSH-ключами:**
  - Интерактивная проверка наличия авторизованных ключей в `~/.ssh/authorized_keys`.
  - Возможность вставить собственный Public Key клиента (с автоматической установкой прав `chmod 600`) либо сгенерировать новую пару Ed25519 прямо на сервере.
* **Защита от потери доступа при отключении паролей (`PasswordAuthentication no`):**
  - Реализован строгий программный предохранитель: вход по паролю физически невозможно отключить, если в `authorized_keys` отсутствует хотя бы один подтвержденный публичный ключ.
* **Интеграция Fail2ban нового поколения:**
  - Настройка `jail.local` с бэкендом `systemd` и автоматической установкой `python3-systemd` для корректного чтения journald на Ubuntu 24.04 LTS и Debian 12.

### 2. Поддержка протоколов следующего поколения (Next-Gen Native)

* **MASQUE (RFC 9484 / RFC 9298 via Sing-box):**
  - Прямое проксирование IP/UDP трафика поверх HTTP/3 QUIC для максимальной устойчивости к блокировкам.
* **ShadowTLS v4 + Shadowsocks-2022:**
  - Интеграция L4 SNI Stream Router под доверенный decoy (`gateway.icloud.com`) с шифрованием `2022-blake3-aes-256-gcm` и поддержкой `udp_over_tcp`.
* **Wstunnel over Nginx L7:**
  - Туннелирование WebSocket через стандартный порт 443 HTTPS с защитой префиксом пути.
* **Server-Side Zapret nfqws:**
  - Встроенный демон десинхронизации DPI ТСПУ через `iptables` NFQUEUE (`connbytes 1:6`, `split2`, `md5sig,badseq`).

### 3. Квантово-устойчивые ключи ML-KEM-768 (EnKey)

* В генератор клиентов Xray добавлен автоматический вывод публичного ключа инкапсуляции Post-Quantum ML-KEM-768 (`EnKey`), готовый для использования в современных версиях Xray-core v26+.

## 📋 Инструкция по установке и обновлению

Запуск обновленного мастера:

```bash
curl -sSL "https://raw.githubusercontent.com/torrua/Nginx-L4-Stream-Router-Mask-for-3x-ui/main/install.sh?v=$(date +%s)" | sudo bash
```

Или прямой запуск расширенного меню:

```bash
curl -sSLO "https://raw.githubusercontent.com/torrua/Nginx-L4-Stream-Router-Mask-for-3x-ui/main/setup_mask.sh" && sudo bash setup_mask.sh
```
