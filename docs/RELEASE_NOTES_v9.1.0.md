# Release Notes: v9.1.0 — Mieru Proxy Protocol, User Management & UX Optimization

**Дата релиза:** Октябрь 2026  
**Ветка / Статус:** Минорный релиз v9.1.0 (Next-Gen Anti-Censorship & User Management)

---

## 🎯 Ключевые изменения в v9.1.0

Релиз **v9.1.0** расширяет арсенал средств обхода блокировок внедрением передового протокола **Mieru** (`mita` daemon v3.38.1+), добавляет полноценную утилиту управления пользователями `mieru-mgr`, рандомизирует чувствительные системные пути для защиты от сканирования и оптимизирует пользовательский опыт (UX) при выборе протоколов.

---

### 1. Интеграция протокола Mieru (mita daemon v3.38.1+) «под ключ»
* **Архитектура протокола:** Mieru реализует полнофункциональный SOCKS5/HTTP прокси на базе симметричного аутентифицированного шифрования **XChaCha20-Poly1305**. В отличие от TLS-туннелей, Mieru не формирует характерных TLS-отпечатков (JA3/JA4) и полностью устойчив к активному зондированию (active probing) благодаря уникальному механизму аутентификации пакетов до установления соединения.
* **Изолированный сервис:** Создается выделенный системный пользователь и группа `mita:mita` с минимально необходимыми привилегиями (`CAP_NET_BIND_SERVICE`, `LimitNOFILE=65535`).
* **Защита синхронизации времени:** Интегрирована автоматическая сверка системных часов через `systemd-timesyncd` — критически важная для криптографических меток времени рукопожатия Mieru.

---

### 2. Поддержка одиночного порта и пула портов (Single Port vs Port Range)
* **Режимы прослушивания:**
  * **Одиночный порт:** по умолчанию `8450` (TCP и UDP);
  * **Диапазон/пул портов:** по умолчанию `8450-8455` (TCP и UDP) — сессии клиентов рандомизируются между несколькими портами, что существенно затрудняет идентификацию и избирательную блокировку потоков DPI-фильтрами.
* **Интеллектуальная трансляция портов:** Модуль файрвола UFW (`src/installer/firewall.sh`) и валидатор preflight-проверок автоматически распознают и нормализуют синтаксис диапазонов (`8450:8455` для iptables/ufw).

---

### 3. Автоматическое внедрение ноды Mieru в подписку Clash / Mihomo
* **Интеграция с базой данных 3X-UI:** Модуль `src/panel/reconcile.py` динамически модифицирует `subClashTemplate` в SQLite-базе `x-ui.db`.
* **Формат Mihomo Meta:** В шаблон подписки внедряется нода `type: mieru` с корректными параметрами (`port` либо `port-range`, `transport: TCP`, `multiplexing: MULTIPLEXING_LOW`, `handshake-mode: HANDSHAKE_STANDARD`, `udp: true`).
* **Группы прокси:** Нода автоматически связывается с селектором `PROXIES` и группой автотестирования `AUTO`. Клиенты получают Mieru прямо по своей ссылке подписки 3X-UI.
* **Официальный клиент:** Автоматически генерируется профиль `/root/mieru-client.json` для мгновенного импорта через `mieru apply config`.

---

### 4. Автономный диспетчер пользователей `mieru-mgr` (и `maintain.sh`)
* **Системный CLI:** В `/usr/local/bin/mieru-mgr` (с алиасом `mieru-cli`) развернута утилита для быстрого управления учетными записями Mieru:
  * `mieru-mgr list` — вывод статуса службы, портов и наглядной таблицы пользователей;
  * `mieru-mgr add <имя> [пароль]` — добавление пользователя, генерация персонального клиентского конфига `/root/mieru-client-<имя>.json` и готового YAML-блока для Mihomo;
  * `mieru-mgr del <имя>` — безопасное удаление пользователя (с защитой от удаления последнего оставшегося аккаунта).
* **Интеграция с `maintain.sh`:** Аналогичные действия доступны через флаги:
  * `./maintain.sh --mieru-list-users`
  * `./maintain.sh --mieru-add-user <имя> [пароль]`
  * `./maintain.sh --mieru-del-user <имя>`

---

### 5. Оптимизация мастера выбора протоколов (UX Improvement)
* **Разделение на 3X-UI и внешние сервисы:** Список протоколов в мастере установки (`src/tui/wizard.sh`) и Express-режиме (`src/installer/express.sh`) реорганизован:
  * **По умолчанию включены основные инбаунды 3X-UI:** Hysteria 2, AmneziaWG v3.1, TUIC v5, Shadowsocks 2022, Telegram MTProxy.
  * **Отключены по умолчанию (выбираются по желанию):** AmneziaWG v2.0 (для старых роутеров), а также все внешние протоколы (MASQUE, ShadowTLS v4, Wstunnel, Server-Side Zapret, NaïveProxy, DNSTT, Mieru Proxy, автономный AmneziaWG).
* Отсутствие внутренних конфликтов портов между предустановленными протоколами (AWG v2 на `8444/udp`, MTProxy на `8444/tcp`).

---

### 6. Рандомизация системных путей (Anti-Scanner Hardening)
* Устранены предсказуемые статические значения в переменных окружения по умолчанию:
  * `PANEL_PATH` — случайный URL веб-панели (вместо `my-3x-panel`);
  * `WSTUNNEL_PREFIX` — случайный префикс WebSocket (вместо `/wstunnel`);
  * `AGH_CLIENT_ID` — криптографический случайный Client ID (вместо `home-router`).
