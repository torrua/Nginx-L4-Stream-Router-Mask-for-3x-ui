# Релиз v9.5.0 — Автономный REALITY сканер, Steal Backup (Compat), безопасный экспорт отладочных логов и надежный откат системы

**Дата релиза:** 23 октября 2026  
**Версия:** v9.5.0

В версии v9.5.0 представлен автономный сканер кандидатов REALITY и автоматическое построение пула SNI без внешних бинарных зависимостей, новый совместимый режим Steal-Oneself REALITY Backup (`static.<domain>`), мультиканальный защищенный движок экспорта журналов отладки с расширенным маскированием секретов, а также глубокая переработка подсистемы деинсталляции и отката сервера.

---

## 1. Автономный сканер REALITY и пул маскировки (`src/xray/reality_scanner.py`)

* **Чистая реализация на Python:**
  - Сканер `reality_scanner.py` выполняет проверку кандидатов маскировки напрямую через Python без внешних утилит или Go-бинарников.
  - Полноценный TLS 1.3 Handshake с ALPN `h2` и поддержкой эллиптических кривых `X25519`.
  - Замер сетевой задержки (RTT latency) от VPS до целевых серверов в миллисекундах.
* **Извлечение и валидация SAN (Subject Alternative Names):**
  - Поддержка извлечения доменов из сертификатов как через стандартный SSL-контекст, так и через собственный встроенный парсер ASN.1 DER.
* **Интеллектуальная фильтрация пула SNI:**
  - Автоматическое очищение от служебных, тестовых и внутренних поддоменов (`qa`, `test`, `dev`, `stage`, `corp`, `intranet`, `preview` и т.д.).
  - Очистка wildcard-префиксов `*.` с получением чистого родительского FQDN.
  - Фиксация целевого домена на позиции `0` и сбор оптимального пула из 3–5 доменов для авторотации в 3X-UI.
* **Интеграция в визард настройки TUI:**
  - В `wizard.sh` добавлено автоматическое сканирование пула кандидатов по умолчанию и интерактивная проверка пользовательских доменов на поддержку TLS 1.3, ALPN h2 и уровень задержки.

---

## 2. Резервный режим VLESS Steal-Oneself Backup (`ENABLE_STEAL_COMPAT`)

* **Инбаунд совместимости (`static.<домен>`, порт `47443`):**
  - Добавлена поддержка инбаунда Steal-Oneself с `flow: ""` (без XTLS-Vision), маскирующегося под собственный веб-сервер через субдомен `static.<домен>`.
  - Обеспечивает 100% совместимость с клиентами и сетевыми окружениями, где XTLS-Vision блокируется или не поддерживается клиентским ПО.
* **Сквозная поддержка в стеке:**
  - Поддержка в `env.sh`, Nginx Stream Router (`47443`), автоконфигурации визарда и синхронизации SQLite БД 3X-UI (`reconcile.py`).

## 3. Защищенный мультиканальный экспорт отладочных логов (`src/system/log-export.sh`)

* **Централизованный сбор и экспорт:**
  - Протоколирование всех операций установки в `/var/log/server-setup.log` с правами `0600`.
  - Автоматический сбор диагностики упавших служб из `journalctl` при сбое любого шага.
* **Многоканальный доступ:**
  - **SCP / SFTP:** генерация точных команд скачивания для Windows PowerShell/CMD, macOS/Linux и реквизитов SFTP с автоопределением реального порта SSH и IP.
  - **Веб-ссылка Nginx:** генерация временной защищенной ссылки в веб-директории с криптостойким токеном (24 символа) и 15-минутным таймером самоуничтожения.
  - **Загрузка на Pastebin:** безопасная отправка на `0x0.st` или `bashupload.com`.
  - **Консольный Tail:** быстрый просмотр последних 50 строк журнала прямо в терминале.
* **Усиление безопасности (Security Hardening):**
  - **Удалены уязвимые фолбеки:** полностью убран запуск эфемерного Python HTTP-сервера с открытием глобального порта в UFW.
  - **Принцип Fail-Closed:** устранен опасный fallback `|| cp -f` в санитизации; при любых ошибках парсера выгрузка немедленно прерывается.
  - **Обязательное маскирование перед отдачей:** файл в веб-каталоге всегда проходит процедуру санитизации перед публикацией.
  - **Расширенная защита секретов:** маскируются переменные с пробелами вокруг `=`, ключи WireGuard/AmneziaWG (`PrivateKey = ...`), JSON-поля учетных данных и многострочные блоки PEM приватных ключей.

## 4. Безопасная деинсталляция и гарантированный откат системы (`src/system/uninstall.sh`)

* **Восстановление из снимка состояния:**
  - Добавлена поддержка безопасного извлечения файлов из архивов снимков состояния (`snapshot.tar.gz`) с корректной обработкой относительных путей `./`.
* **Защита пользовательских данных:**
  - Удаление пакетов (`apt purge`) ограничено строгим белым списком, исключая случайное удаление системных утилит хоста.
  - Сохранение пользовательских сайтов и файлов в `/var/www/html`.
* **Селективная очистка файрвола:**
  - Все правила UFW, создаваемые скриптами, помечаются маркером `[vpn-stack]`. При деинсталляции удаляются только они, сохраняя пользовательские правила и политику фаервола.

---

## 5. Повышение отказоустойчивости Nginx Mainline (`src/nginx/install.sh`)

* **Проверка поддержки `ssl_reject_handshake`:**
  - Перед переустановкой бинарника Nginx выполняется функциональный тест на поддержку директивы `ssl_reject_handshake`.
  - Если установлена устаревшая дистрибутивная версия — производится автоматическое бесшовное обновление до официального репозитория Nginx Mainline.
* **Фиксация прав на keyring:**
  - Права на архивный ключ `/usr/share/keyrings/nginx-archive-keyring.gpg` строго выставлены в `0644`.
