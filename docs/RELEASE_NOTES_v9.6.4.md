# Релиз v9.6.4 — Нативная поддержка Alpine Linux & OpenRC, ежемесячный автосброс трафика и совместимость с 3X-UI v3.11+

**Дата:** 28 октября 2026 г.  
**Версия:** v9.6.4

Версия v9.6.4 представляет нативную поддержку ультралегковесного дистрибутива **Alpine Linux** и систем инициализации **OpenRC** через единый слой абстракции OS Abstraction Layer (`src/system/service.sh`), автоматический ежемесячный сброс счетчиков трафика инбаундов и клиентов 3X-UI, анти-DPI защиту от блокировок ТСПУ (отключение фрагментирующего ML-KEM в Mihomo и рандомизация keepalive AmneziaWG) и строгое повышение отказоустойчивости CLI.

---

## 🚀 Ключевые изменения и улучшения

### 1. Нативная поддержка Alpine Linux и систем инициализации OpenRC
* **OS Abstraction Layer (`src/system/service.sh`)**:
  * Реализована универсальная обертка управления службами (`service_enable`, `service_start`, `service_stop`, `service_restart`, `service_is_active`, `service_reload`), автоматически определяющая окружение (`systemd` vs `OpenRC`).
  * Для систем с OpenRC развернут генератор init-скриптов `/etc/init.d/*` с использованием современного демона надзора `supervise-daemon`.
  * Охвачены все сервисы стека: 3X-UI, Nginx, Sing-box, Xray, Mieru, Hysteria 2, AdGuard Home, Caddy Naïve, DNSTT.
* **Пакетная база Alpine (`apk`)**:
  * Полный маппинг системных пакетов в `src/system/packages.sh` (включая автоматическое подключение репозиториев `edge/community` и `edge/testing`).
  * Автоматический выбор бинарных файлов Sing-box архитектуры `musl` для корректной работы без `glibc`.
  * Корректная изоляция пользователя веб-сервера (`nginx` для Alpine, `www-data` для Debian/Ubuntu).
* **Модуль ядра AmneziaWG (Kbuild на Alpine)**:
  * Реализована автоматическая сборка модуля `amneziawg.ko` из исходников под установленное ядро `linux-lts` или `linux-virt`.
  * Настроен хук `/etc/kernel-hooks.d/50-amneziawg` для автоматической пересборки при обновлениях ядра Alpine.
* **Снапшоты и деинсталляция**:
  * Скрипты `snapshot.sh` и `uninstall.sh` адаптированы для сохранения состояния и чистого удаления пакетов через `apk` и сервисов через `rc-update`.

### 2. Автоматический ежемесячный сброс трафика 3X-UI
* **Ежемесячный сброс в полночь 1-го числа**:
  * Во все инбаунды 3X-UI при создании и синхронизации (reconcile) проставляется автоматический сброс: `traffic_reset = 'monthly'`, `traffic_reset_day = 1`.
  * Панель 3X-UI в 00:00:00 1-го числа каждого месяца обнуляет счетчики трафика на инбаундах, обнуляет потребление клиентов в таблице `client_traffics` и автоматически разблокирует клиентов, исчерпавших месячный лимит.
* **Самоисцеляющаяся миграция (Self-healing SQLite)**:
  * Скрипт проверяет наличие колонок `traffic_reset`, `traffic_reset_day` и `last_traffic_reset_time` в таблице `inbounds`, при необходимости выполняет `ALTER TABLE` и мигрирует все инбаунды со статусом `never`/`NULL` на `monthly`.
* **Синхронизация профилей клиентов**:
  * В JSON-настройки инбаундов и таблицы `clients` / `client_traffics` транслируются параметры `trafficReset: "monthly"`, `trafficResetDay: 1`, `resetDay: 1`.
* **Настройка через переменные окружения**:
  * Добавлены переменные `INBOUND_TRAFFIC_RESET` (по умолчанию `"monthly"`) и `INBOUND_TRAFFIC_RESET_DAY` (по умолчанию `1`).

### 3. Совместимость с 3X-UI v3.11.0 и защита от блокировок ТСПУ (РФ)
* **Защита VLESS REALITY от блокировок ML-KEM (`mihomo_x25519 = 1`)**:
  * В таблицу `hosts` добавлен параметр `mihomo_x25519 = 1` для хостов Steal REALITY и Classic REALITY.
  * Это предотвращает принудительное использование пост-квантового шифрования `X25519MLKEM768` клиентами на базе ядра Mihomo, устраняя фрагментацию ClientHello на два пакета (>1800 байт), вызывающую блэкхол со стороны DPI ТСПУ.
* **Рандомизация PersistentKeepalive для AmneziaWG (`15-25 сек`)**:
  * Генерация клиентских конфигов и инбаундов переведена на случайный интервал `15-25` секунд вместо дефолтных 25 секунд для размытия периодических паттернов WireGuard в DPI мобильных операторов.
* **Безопасный скоуп API токена ноды (`node-admin`)**:
  * Генератор токенов узлов панели использует изолированный скоуп `node-admin`, предотвращая эскалацию привилегий до полного администратора панели.
* **Массивы `alpn` для VLESS xHTTP**:
  * Нормализация параметра `externalProxy.alpn` в вид массива `["h2"]` устраняет ошибки валидации формы в веб-интерфейсе 3X-UI v3.11+.

### 4. Повышение отказоустойчивости CLI
* **Безопасность строгого режима `set -u` (`nounset`)**:
  * Устранены сбои `unbound variable` в скриптах конфигурации и формирования итоговой сводки `report-web.sh` при неопределенных опциональных переменных `ENABLE_NODE_TOKEN`, `ENABLE_WARP` и `ENABLE_AGH`.
